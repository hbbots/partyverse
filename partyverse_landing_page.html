ENGINE ARCHITECTURE

Zero Bloat. Direct CustomPainter Canvas.

Modern multi-game arcade apps are often plagued by 500MB+ asset bundles, embedded webviews, or heavy Unity runtimes. PartyVerse is built natively with lean mathematical Dart pipelines.

Mathematical Rendering

Every pitch, stadium stand, articulated stick figure, net mesh, and shadow is rendered dynamically using cubic Bézier paths and radial shader masks. Zero static bitmap sprites are loaded.

60/120 Hz Sync • 0 External Textures

Handcrafted Physics

Sub-step elastic collisions, 2.5D perspective projection math, friction dampening, and gravitational curve attractors were coded directly in Dart without third-party physics libraries.

Euler Integration • Sub-step Separation

Native Tactile Feedback

Coupled with device haptic generators (heavy impact on wickets, light click on bounces) and non-blocking background disk persistence to eliminate dropped frames during state updates.

HapticFeedback API • Async State
